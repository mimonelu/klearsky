# 閲覧数（`viewCount`）

AppView が投稿者本人にだけ返すポストの閲覧数を表示する（#125）。

## AppView の挙動

- `PostView` の任意項目 `viewCount`。ログイン中のユーザー自身のポストで、閲覧数が 100 以上、かつ機能の開始日時（非公開）以降のポストにだけ付く
- 値は公式アプリでの閲覧から推定した概算。Klearsky での閲覧は数えられていない可能性が高い
- AppView 側の取得に 100ms の時間制限があり、間に合わないと項目ごと省かれる。同じポストでも応答によって付いたり付かなかったりする
- フィードや検索の `PostView` にも付くが、引用先（`embed#viewRecord`）には付かない
- `@atproto/api` の型に含まれていない時期があったため、`TTPost` に独自に定義している

## 表示

- 表示位置は本文末尾のスレッド番号の右隣で、翻訳リンクより前（`HtmlText` の `after` スロット）
- `viewCount` があれば画面を問わず表示する。投稿者本人かどうかや閲覧数の下限は AppView 側に任せ、表示側では確かめない
- フィードでは過去取得と抜け漏れ取得でポストのデータを更新しないため、値が古いまま残る。新着取得では `post` を置き換えるため、`viewCount` が省かれた応答だと表示が消える
- 「リアクション数の非表示」が有効な時は表示しない
- 公式アプリは年齢を申告していないユーザーと 18 歳未満のユーザーに表示しないが、Klearsky は年齢の申告状態を扱っていないため、この条件では隠さない
- 本文が空のポストでも本文の部品を描画し、スレッド番号と閲覧数を表示する

## 更新

- `updatePostProps` では、`viewCount` がある応答の時だけ値を更新する。省かれた応答で表示が消えないようにするため
